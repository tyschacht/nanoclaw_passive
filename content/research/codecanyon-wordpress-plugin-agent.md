# CodeCanyon WordPress Plugin Marketplace — Not Viable

## What It Claims to Be

CodeCanyon (Envato's marketplace) hosts 55,000+ WordPress plugins, themes, and scripts with 2.3 million+ sales. An AI agent generates WordPress plugin code (PHP), submits it to CodeCanyon, and earns 62.5% of sales revenue passively. Average annual plugin income on CodeCanyon: ~$3,838/year (~$320/month). Top plugins earn $10K–$50K+/month. The newly released WordPress 7.0 AI Client API (April 2026) makes building AI-powered plugins easier.

## Why It Doesn't Work Agentically

- **No programmatic submission API**: CodeCanyon's submission process requires uploading a zip file, filling a multi-page form, and submitting via Envato's web dashboard. There is no REST API or CLI for programmatic item creation or submission. The same dead-end confirmed for Gumroad, Lemon Squeezy, and Payhip applies here. An agent cannot list items without human involvement.
- **Manual review bottleneck**: Every new submission undergoes a human quality review by Envato's staff — typically 5–15 business days, sometimes longer. Unlike Framer or Shopify App Store (where a single human submit is a quick one-time action), CodeCanyon reviews are unpredictable and frequently reject submissions for quality or policy reasons. The rejection rate for new authors is high. This makes it harder to pipeline submissions.
- **Oversaturated and declining market**: The WordPress plugin market is mature and crowded. The top-1% of plugins earn most of the revenue. AI-generated plugins face a quality ceiling — reviewers explicitly evaluate code quality, UI, and support documentation. Generic or template-like plugins are rejected. This is not a "build many, let the long tail compound" opportunity.
