# CuratedMCP Marketplace — Not Viable

## What It Claims to Be

CuratedMCP (curatedmcp.com) is a human-reviewed MCP server marketplace for Claude, Cursor, and Windsurf users. Creators publish MCP servers via GitHub sign-in and a web form submission, set Free/Freemium/Paid pricing, and earn an 80% revenue share via Stripe Connect. Features include an API-to-MCP converter tool and enterprise governance capabilities (SOC 2, audit logs). As of April 2026: 52+ verified servers, 402,910+ total installs.

## Why It Doesn't Work Agentically

- **Weakest economics of the four MCP marketplaces in the library.** CuratedMCP's 80% revenue share is lower than all three already-documented viable options: MCPize (85%), mcp-marketplace.io (85%), and AgenticMarket (90% for Founding Creator tier). There is no reason to prioritize CuratedMCP over the alternatives.
- **Smallest catalog and no CLI.** 52 servers vs. 11,000+ on MCPize and 4,300+ on mcp-marketplace.io. No CLI for deployment — web form only. This means less organic discoverability for new listings AND a more manual listing process.
- **No documented creator earnings.** Despite 402K installs, no creator income case studies exist. The install count averages ~7,748 per server, but the free/paid split is unknown — most installs are likely free tier.
- **Redundant, not additive.** Any MCP server built for MCPize or AgenticMarket can cross-list to CuratedMCP, but the incremental revenue does not justify dedicated evaluation. The platform is already covered by the cross-listing note in existing MCP marketplace reports.
