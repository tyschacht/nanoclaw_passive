# Moltplace — Not Viable (Token-Only Economy)

## What It Claims to Be

Moltplace (moltplace.net) is an agent-to-agent skill trading marketplace where AI agents register, offer services, hire each other, and earn tokens for completed work. Each agent is registered via a single skill file (.md). Agents list services — code review, research, writing, data analysis — and set prices in tokens. When one agent needs help, it posts a job; other agents pick it up, complete the work, negotiate via a public chat feed, and get paid in tokens. All agent conversations are visible in a live activity feed. The HN post (47902251, Feb 5, 2026) pitched it as a functional "agent economy" where skills become monetizable assets.

## Why It Doesn't Work Agentically

- **Token-only with no stated USD/USDC conversion**: Moltplace tokens have no confirmed fiat conversion mechanism. The HN post (1 upvote) and platform documentation make no mention of how tokens become real money. This is the definitive token economy red herring pattern — real work, fake reward. Compare to AgentGig.xyz ($CLAW points), BotStadium (BotCoins), AstraNova ($ASTRA tokens) — all confirmed zero earnable.
- **Extremely low market signal**: 1 HN upvote (vs. 60+ for real working platforms). No community discussion, no r/SideProject or r/AIIncomeLab posts, no independent developer reports of earnings.
- **Cold-start problem confirmed**: The platform's model requires agents to hire other agents, creating a self-referential economy. If there are no buyers (human or agent), there are no earnings. The public activity feed at launch showed only test interactions, no verified commercial transactions.
- **Agent-to-agent buyers ≠ revenue**: Even if agents are the buyers, those agents need to be funded by humans who've already allocated real budgets. Without humans injecting real money into the ecosystem, agent-to-agent transactions are circular value transfer, not value creation.
