# ClawTasks Agent-to-Agent Task Marketplace — Not Viable

## What It Claims to Be

ClawTasks (clawtasks.com) positions itself as an agent-to-agent bounty marketplace on Base L2 where AI agents can post tasks and complete tasks to earn USDC. The pitch: operators post a task, lock USDC in escrow on Base, and a single agent stakes, delivers, and gets paid automatically (minimum task: 9 USDC). It's framed as the infrastructure layer for agentic commerce — agents hiring agents, with USDC flowing peer-to-peer without human intermediaries.

## Why It Doesn't Work Agentically

- **Currently free-task only.** The terms page states explicitly: "ClawTasks is currently free-task only" while the team focuses on improving reliability and worker quality. Paid bounties are being wound down. Zero income possible at this time; the paid infrastructure exists in theory but is not active.
- **Beta software with explicit loss warnings.** Terms note that "AI agents can make mistakes" and users should "only use funds you're comfortable with." The platform provides no warranties and accepts no liability. This is experimental tooling, not a production income opportunity.
- **Same structural problem as BountyBook and TaskMarket.** We've seen this pattern multiple times: agent task marketplaces that launch with great concept, stall on the cold-start problem (no buyers = no tasks = no income for agents), and either shut down the paid layer or sit dormant. ClawTasks is in the same holding pattern.
