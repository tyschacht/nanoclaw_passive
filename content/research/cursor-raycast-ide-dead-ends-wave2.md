# Cursor/Raycast/Slack/HuggingFace — Not Viable

## What It Claims to Be

Four popular developer platforms appear to offer creator income opportunities for AI-powered extensions, plugins, bots, and datasets. Cursor (2B+ in annualized revenue, 3M+ developer users) launched a Plugin Marketplace in February 2026. Raycast ($8/mo Pro plan, 2M+ macOS developers, 1,500+ extensions) has a thriving extension community. Slack (320M MAU) has an App Directory with 2,886 apps. Hugging Face (2.4M models, 730K datasets) is the dominant AI model hosting platform.

## Why They Don't Work Agentically

- *Cursor Marketplace — free only, no developer revenue:* Cursor's Plugin Marketplace (launched February 2026) bundles MCP servers, skills, subagents, and hooks. All plugins are free to install — Cursor has not implemented paid extension revenue sharing. Partners (Amplitude, AWS, Figma, Linear, Stripe) use plugins for distribution of their own SaaS products, not as income-generating items. No documentation or announcement of paid plugin tiers as of April 2026. Same pattern as VS Code Marketplace (never had paid extensions despite 14M+ daily users). The correct agentic income path for tool-style products is [[jetbrains-plugin-marketplace-paid]] (85% rev share, 8M developers, first manual upload then headless updates).

- *Raycast extensions — free community store, zero creator income:* Raycast has 20K+ extension developers and 1,500+ extensions in a community store. All extensions are free. Raycast's revenue comes from Pro ($8/mo) and Teams ($12/user/mo) subscriptions — zero creator revenue sharing exists. Extensions must be open-sourced on GitHub (per Raycast developer program terms). No indication from Raycast roadmap that paid extension tiers are planned. The developer program is for building reputation and getting featured, not for earning money.

- *Slack App Directory — no confirmed rev share program for paid apps:* Slack has a $30/user/mo business plan and 320M MAU, but third-party paid apps route buyers to the developer's own Stripe/billing (Slack does not handle payment collection for most apps). The "Slack in-app purchase" system used by some apps requires direct relationship with Slack's business development team. No self-service paid app distribution program with documented revenue share exists. Confirmed: zero programmatic submission API (all listings via web portal). Build Slack bots for clients via the agency model (Stammer.ai white-label resell approach) but not as a marketplace product.

- *Hugging Face datasets — no paid creator marketplace:* HuggingFace hosts 730K+ datasets but all are part of a free, open-source ecosystem. HuggingFace's revenue comes from compute (Spaces, Inference Endpoints) and enterprise licensing — zero creator revenue sharing for dataset authors. The Hugging Face Discuss forums confirm model/dataset authors earn $0 from HuggingFace itself. The only dataset income models require off-platform licensing agreements with enterprise buyers (manual B2B deal-making, not passive).
