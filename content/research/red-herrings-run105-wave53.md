# Run 105 Wave 53 Bundle — Not Viable

## What They Claim to Be

A collection of three items evaluated this run that all fail the agentic passive income test:

1. **Binance Wallet Prediction Markets API** (binance.com/prediction-market, June 8 2026 launch) — API for trading bots targeting prediction markets on BNB Chain via Predict.fun protocol
2. **ClawTown** (clawtownai.com, June 20 2026 HN score 1) — "Autonomous agents bid on tasks and settle out of escrow"
3. **Botpool.ai** (botpool.ai, June 18 2026 HN score 7) — "20k+ AI Freelancers Available for Hire"

## Why They Don't Work Agentically

**Binance Wallet Prediction Markets API:**
- US residents are blocked — Binance is US-banned; geo-restricted in 44+ countries; limits operator base
- No published maker rebate program — unlike Polymarket (25%) or Kalshi (documented LIP), Binance/Predict.fun has no confirmed passive liquidity provision incentive
- API is in beta; Predict.fun mainnet API key requires Discord contact (not instant self-service)
- Settlement in USDT on BNB Smart Chain — smart contract risk + stablecoin bridge risk
- Binance KYC required — accounts linked to real identity, with Binance's history of banning power users
- Without a maker rebate, income requires directional prediction alpha or spread capture — both capital-dependent, not passive

**ClawTown:**
- 24th+ cold-start agent task marketplace pattern — follows ClawGig, BountyBook, SwarmDock, ugig.net, Bountycaster, algora-general, etc.
- Payment rails: Proprietary TTT token explicitly labeled "play-money" on the platform — not USD, not USDC, no exchange rate, no off-ramp
- Escrow: Admin-mediated, not on-chain
- Scale at launch: 8 total tasks (2 open), 10 agents, 530 TTT total escrow = $0 real value
- Related note: "Claw Earn" (aiagentstore.ai/claw-earn) is a SEPARATE product using real USDC-on-Base escrow — not the same as ClawTown

**Botpool.ai:**
- Category miss: "AI Freelancers" are human professionals who build AI products — not autonomous agents
- Payment rails: Payoneer + Stripe in local fiat — no USDC, no agent API
- Autonomous agents cannot register, bid, or receive payment on this platform
- This is a legitimate human freelance marketplace for AI skill professionals, not an agent economy platform
