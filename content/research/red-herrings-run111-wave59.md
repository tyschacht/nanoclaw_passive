## Why Each Doesn't Work Agentically

### 1. Moon Dev — Same cherry-pick pattern (8th instance)
- **No sustained live P&L**: Videos show cherry-picked trades or short-window backtests (identical pattern to prior moon-dev-liquidation-cascade-polymarket NOT_VIABLE)
- **Paid course funnel**: Full code is gated behind "private live stream" at moondev.com (not shared freely)
- **"Never Lost" claim**: Statistically impossible at scale — any claim of a Polymarket bot with no losing trades is backtested on a short cherry-picked period
- Cross-platform arb is already VIABLE via [[research/polymarket-kalshi-cross-platform-arbitrage]]; weather bot VIABLE via [[research/polymarket-weather-bot-gfs-edge]]. Moon Dev adds nothing new.

### 2. Cyberghost Polydict — Unverified, redundant
- **4,007 views, unknown channel**: No verified track record for Cyberghost So2
- **"$2,000 from arbitrage"** is a single session claim with no sustained P&L data
- Cross-platform PM arbitrage is already covered by [[research/polymarket-kalshi-cross-platform-arbitrage]] (VIABLE, open-source `pmxt` library). Polydict is a proprietary wrapper of the same concept.
- Score below standalone viable threshold; claim unverifiable.

### 3. Genspark Affiliate Marketing — Audience bottleneck, covered
- **Audience bottleneck**: Affiliate marketing income scales with traffic/audience. Getting that traffic is irreducibly human (SEO, email list building, social following)
- **Genspark has no creator marketplace or rev-share program**: It's a $24.99/mo AI workspace tool. "Earn with Genspark" = use Genspark to build content → monetize via affiliates on YOUR audience → same bottleneck as beehiiv/picsart
- Joshua Mayo's channel promotes YouTube coaching (moondev.com→go.thecontentgrowthengine.com) — the actual income is from YouTube views + course sales, not from any autonomous mechanism
- 13th+ affiliate marketing "side hustle" video in this category. Pattern confirmed.

### 4. AI Photography (Nano Banana + Upwork) — Service model, not passive
- **Client acquisition is irreducibly human**: The poster uses Upwork applications + cold email outreach with custom visual samples per prospect
- **Creative judgment required per project**: Scoping, pricing, and revisions all require human creative decision-making ("What problem is this business actually trying to solve?")
- **$5k/month from 6 months of active freelancing**: Not passive income — active freelance service business that uses AI to improve productivity
- Previous Nano Banana evaluation was n8n-instagram-nano-banana-2 (NOT_VIABLE, May 2026, audience bottleneck). This is the same tool applied to Upwork/B2B services — different delivery channel, same human-required client management.
- Agentic viability: 2/10. An agent can batch-generate images but cannot scope projects, negotiate pricing, or develop client relationships.

### 5. Story Protocol IP Royalties — Token-ecosystem dependent
- **$IP token income, not USD**: Royalties are paid in $IP tokens on the Story blockchain, whose value tracks the Story protocol's token market cap. Same fundamental disqualifier as $VIRTUAL (Virtuals ACP), $XAGT (AgentChain), $TAO (Bittensor)
- **Royalty trigger requires derivative works**: Your registered IP only earns when another agent explicitly licenses it. Nobody is browsing the Story registry to find which 61-regex dataset to license — adoption is near-zero outside the Story Protocol developer community
- **No documented individual income in USD**: 0.3B IP assets registered but zero verified USD payouts from independent creators
- **Programmable IP = interesting infrastructure, not income mechanism**: The MCP server for Story Protocol enables on-chain IP interactions but doesn't solve the royalty discovery and payment trigger problem
