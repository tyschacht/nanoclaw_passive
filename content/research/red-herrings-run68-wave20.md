## 1. Noos Network ($NOOS Token Compute Staking)

### What It Claims to Be
Noos Network (noosnet.medium.com) is a "Proof of Agentic Contribution" (PoAC) blockchain platform where AI agents earn $NOOS tokens for completing intelligent tasks. Videos like "Run a Noos ICN Node — Power the AI Economy & Earn $NOOS" (Wills, March 2026) and "Noos Node Explained in 60 Seconds" (U_major, April 2026) pitch it as AI agent income. A more recent video "What is Noos? AI Agents That Earn Money" (Ubong Akpan, May 15 2026) got the video surface attention again.

### Why It Doesn't Work Agentically
- **Token-only income** ($NOOS, not USD/USDC): 16th+ instance of this pattern in the library. No confirmed withdrawal to fiat currency, no USD-denominated payout.
- **Compute staking**: Noos node operation requires running infrastructure, not task completion. Same pattern as Bittensor Ridges (documented in red-herring patterns: "TAO token mining operations requiring $1K-$5K registration fee in TAO + GPU server + low-latency competition").
- **No developer API**: The MetYa + HolmesAI partnerships are for Web3 social, not for individual developers to earn USD by submitting tasks via API.

## 3. Claude for Small Business (Anthropic First-Party Product)

Anthropic launched "Claude for Small Business" on May 13, 2026 — 15 prebuilt agentic workflows, 15 reusable skills, and 8 integrations (QuickBooks, PayPal, HubSpot, Canva, DocuSign, Google Workspace, M365, Slack). Workflows handle invoice chasing, payroll planning, month-end close, CRM sync, and contract routing.

### Why It Doesn't Work Agentically
- **Anthropic-built, not third-party**: Anthropic creates and maintains all 15 workflows and 15 skills directly. There is no third-party skill submission marketplace for Claude for Small Business at launch.

## 4. n8n Markets (n8nmarkets.com) — 90% Rev Share, No Listing API

### What It Claims to Be
n8n Markets (n8nmarkets.com) is the leading marketplace for n8n workflow templates with 8,000+ automation professionals. Creators earn 90% revenue share (10% platform fee) via instant Paddle payouts. Income examples include "$47K/year from 3 workflows" and "$3,200/mo from 5 templates." It directly competes with ManageN8N (already in library).

### Why It Doesn't Work Agentically
- **No listing API**: n8nmarkets.com has no public API for programmatic workflow submission. The listing process requires manual web UI interaction — the same bottleneck that made ManageN8N a NOT_VIABLE standalone play.
- **Complement, not standalone**: Works as a MANUAL distribution add-on to the existing [[whop-n8n-automation-templates]] pipeline. An agent generates the workflow JSON + Whop auto-lists it; a human can then also upload to n8nmarkets.com for additional reach. But the n8nmarkets.com listing is a human step.
- **Lower rev share than Whop**: Whop takes 3% vs n8n Markets 10%. Whop has 450K+ users and full API automation. n8nmarkets has 8K niche professionals.
- Note: n8nmarkets IS useful as a secondary distribution channel after Whop (human one-time upload, then passive sales). But cannot be a standalone agentic income mechanism.

## Pattern Notes

- **Token staking red herring (instance #16+)**: Noos is the latest in a long series (Bittensor, ALBA, $ASTRA, Retake Clanker, etc.). The pattern: "Proof of X Contribution" mechanism → tokens with no confirmed USD withdrawal → not viable. Do not evaluate new PoX consensus chains unless USD withdrawal is confirmed and documented.
- **Audience-first content income**: Luna Vega + AIpreneur continue the pattern: Claude Code is a TOOL, the income comes from an existing human audience. These will keep appearing in YouTube searches.
- **Anthropic first-party products**: Any new Anthropic product launch (Claude for Small Business, Claude Design, Claude Cowork) is NOT a creator income opportunity unless a third-party submission API is explicitly confirmed.
