# Wave 48 Bundle — Not Viable

Four patterns identified in this run — all fail the agentic income filter for distinct reasons.

---

## 1. Travala Travel MCP – Developer Rebate Program

### What It Claims to Be

Travala launched the world's first "end-to-end agentic AI travel protocol" on June 10–11, 2026. Built on Base L2 + x402 protocol, the Travala Travel MCP allows AI agents to search 2.2M+ hotels and book autonomously. Developers who build Travala-integrated AI travel agents earn a 10% cbBTC (Coinbase Wrapped Bitcoin) rebate on every successful booking, settled on-chain.

### Why It Doesn't Work Agentically

- *User acquisition bottleneck*: The 10% rebate only triggers when a USER chooses to use your travel agent AND authorizes the payment. The booking is "autonomous" but requires a human traveler to initiate each trip and approve each transaction — there is no self-contained loop. Income = $0 without an audience.
- *Affiliate/referral model in disguise*: This is structurally identical to travel affiliate programs (booking.com, Expedia) — build an agent, get 10% of bookings made through your integration. Not passive; not scalable without marketing. Fails the "agent does the work" filter.
- *cbBTC payout complexity*: Rebate paid in Coinbase Wrapped Bitcoin, not USD or USDC. Adds conversion step and crypto price risk.

|---|---|---|
| Agentic viability | 4 | Agent handles the booking flow but human must initiate + authorize each transaction |
| Setup effort | 6 | x402 + MCP integration is clean; Base L2 wallet setup |
| Yield potential | 5 | 10% of hotel bookings is meaningful IF you have traffic; $0 without audience |
| Risk | 7 | cbBTC is real value; low legal risk |
| **Overall** | **5.5** | |

## 2. Polyforge.info – Polymarket "Farm Script"

### What It Claims to Be

Two YouTube videos ("✅FREE POLYMARKET SCRIPT | AUTO POLYMARKET FARM SCRIPT | EARNING ON POLYMARKET") direct to polyforge.info, promising an automated Polymarket "farm" script that earns passively. Videos tag "drain," "CLAWDBOT," "moltbot," and similar scam-adjacent terms.

### Why It Doesn't Work Agentically

- *Scam indicators confirmed*: Tagged keywords match the exact drain contract scam pattern (see kent-davis-mev-drain-scam report). "Farm script" + external site redirect + vague earnings claims = wallet drain setup.
- *No documented earnings, no legitimate mechanism*: No P&L, no GitHub source, no technical mechanism. Polymarket doesn't have a "farming" mechanic — the model doesn't exist.
- *Pattern recognition*: Same template as kent-davis-mev-drain-scam (April 2026): "paste script, fund wallet, earn passively" = irreversible loss pattern.

## 3. AIBIZ / .aibiz SLD Token Scheme

### What It Claims to Be

A YouTube video (e2W channel, 0 views, June 12 2026) promotes ".aibiz names" as "business infrastructure." The pitch: register an SLD (Second-Level Domain), sell sub-agents at any price (AIBIZ keeps flat 5 BZeUSD fee), rent/lease agents for recurring 70% share, earn 10% on "your whole namespace."

### Why It Doesn't Work Agentically

- *Virtual currency (BZeUSD)*: All earnings denominated in "BZeUSD" — not USD, USDC, or any established stablecoin. No documented conversion to fiat.
- *19th+ token-only agent economy*: Same pattern as XAGT (AgentChain), ASTRA (AstraNova), BotCoins (BotStadium), NEAR (NEAR AI), etc. — virtual currencies with no proven real-world offramp.
- *Zero community presence*: 0 views, no Reddit/HN discussion, no GitHub.
- *Cold-start marketplace pattern*: Needs sub-agent buyers before any income flows.

## 4. Superteam Earn – Solana Bounties for AI Agents

### What It Claims to Be

Superteam Earn is the Solana ecosystem's premier bounty platform with USDC bounties averaging $1,500 per task. It has a purpose-built Agent API allowing autonomous AI to discover and submit to agent-eligible listings. Aurora AI and "Blaze" AI experiments (DEV.to, June 2026) both attempted Superteam Earn as a primary income source.

### Why It Doesn't Work Agentically

- *80% KYC/AI-block rate*: Despite having an Agent API, 80% of Superteam Earn bounties explicitly block AI submissions or require KYC that agents cannot pass. The "Agent API" is aspirational marketing more than a working income path.
- *Zero documented earnings*: Both Aurora and Blaze AI experiments resulted in $0 earned after active attempts. Blaze had a pipeline of "$5,850 in potential prizes" but won nothing across 4 bounties competing against 479 other entries.
- *Technical complexity*: Agent-eligible bounties tend to be high-complexity Solana development tasks (rebuilding API key management as on-chain programs, etc.) — beyond the autonomous coding capacity of current agents without extensive human debugging.
- *Analogous to GitHub general bounty hunting*: Same conclusion as github-general-bounty-hunting-not-viable (June 11, 2026). General bounty hunting = $0 documented. Algora TRANSLATION niche is the specific exception, not the rule.
