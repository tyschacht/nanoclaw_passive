# Platform Dead Ends Wave 8 — Not Viable

Four patterns evaluated this run that failed the agentic viability test.

---

## 1. AI Trading Bot (Claude + Webull API)

### What It Claims to Be
Building an autonomous AI trading system using Claude + Webull's broker API to make stock trades without manual intervention. Daniel Thacker YouTube video "Part 1: Building an AI trading bot w/ Claude + Webull API" (1,108 views, April 2026).

### Why It Doesn't Work Agentically
- Capital-dependent: agent needs real money deployed; not a labor-income model
- Confirmed red herring pattern: Nate Herk's 30-day live test (eu8UJtuIi-E) showed net loss –$367; no verified 4-week+ positive P&L documented for any indie Claude trading bot
- "Part 1" framing = no live results yet; check back only if Part 3+ shows 30+ day verified P&L

### Scores
| Criterion | Score (1-10) | Notes |
|---|---|---|
| Agentic viability | 7 | Can be fully automated |
| Setup effort | 5 | API integration ~20 hrs |
| Yield potential | 3 | No verified sustainable returns; pattern shows losses |
| Risk | 3 | Capital at risk; losing money is the most common outcome |
| **Overall** | **4.5** | |

YouTube: Daniel Thacker (eFEmkbmOYMM, April 2026) — https://youtube.com/watch?v=eFEmkbmOYMM

## 3. ToolMesh (YAML-Driven MCP Tool Generator)

### What It Claims to Be
"Turn any REST API into MCP tools via declarative YAML (.dadl files)" — ToolMesh, HN Show HN post (April 2026). Secure execution layer between AI agents and infrastructure.

### Why It Doesn't Work Agentically
- Infrastructure tool, not an income mechanism — it enables MCP server development, it doesn't earn money
- Apache 2.0 open source; Dunkel Cloud GmbH product; no creator revenue sharing program
- The income play would be: build YAML spec files for popular APIs and sell them as MCP servers on MCPize/AgenticMarket — but that's the existing MCP marketplace cross-listing strategy already documented, not ToolMesh-specific
- HN score not tracked (new post at time of research); no documented creator earnings

### Scores
| Criterion | Score (1-10) | Notes |
|---|---|---|
| Agentic viability | 5 | Can generate YAML specs, but no revenue mechanism built in |
| Setup effort | 6 | YAML spec writing is easy |
| Yield potential | 3 | No marketplace; earning requires listing elsewhere (already covered) |
| Risk | 9 | No risk — just not viable as standalone income |
| **Overall** | **5.75** | Below threshold; treat as infrastructure, not income source |

## 4. Oracle Fusion AI Agent Marketplace

### What It Claims to Be
Oracle's Fusion Applications AI Agent Marketplace where partners publish validated AI agent templates for enterprise customers. "More than 100 validated partner-built AI agents" from firms like Accenture and Deloitte.

### Why It Doesn't Work Agentically
- Partner-gate: requires Oracle PartnerNetwork membership; individual developers explicitly excluded
- Partners listed are Infosys, IBM Consulting, KPMG, Accenture, Deloitte — enterprise SI firms only
- No revenue sharing model documented; agents are listed for free to drive Oracle cloud adoption
- Same partner-gate pattern as Make.com/Anthropic/Salesforce AppExchange/Zoom (8th instance)
