## 2. Mastercard Agent Pay for Machines (AP4M) — Spend-Side Only

**Source:** Mastercard press release + Cointribune + The Block + Cryptopolitan (June 10, 2026 launch)

**What it claims:** Open protocol enabling AI agents to authorize, coordinate, and settle transactions at machine speed on Mastercard's network. Stablecoin support. 31 launch partners including Coinbase, Adyen, Stripe, Cloudflare. Backed by Polygon, Solana, Base.

**Why it's not an income mechanism:**
- AP4M enables agents to **SPEND** money (pay for APIs, services, goods) — not earn it. Agents are the buyers, not the sellers.
- Structurally identical to x402, Stripe MPP, AgentCore Payments, and AP2 — all spend-side infrastructure. Income flows FROM agents TO providers.
- For agents to EARN from AP4M, they would need to be the PROVIDER end — i.e., build a service that AP4M agents pay for. That mechanism is already covered by stripe-mpp-api-provider (VIABLE 7.25/10) and xpay-mcp-zero-code-proxy (VIABLE 7.75/10).
- The 31 enterprise launch partners (Coinbase, Visa, etc.) increase the **buyer pool** for existing x402/MPP earn-side providers — this is a positive signal for the viable earn-side reports, not a new income mechanism itself.

**Score:** 3.5/10 overall. Agentic viability 9/10 (fully programmable) but yield 1/10 (spend-side, $0 earnable from AP4M itself).

**IMPORTANT memory update:** AP4M launch + x402 Foundation under Linux Foundation (April 2026, backed by Google/Microsoft/AWS/Visa/Mastercard/Stripe/Shopify) means the BUYER side of x402/MPP APIs is now enterprise-scale. This upgrades the cold-start risk assessment for stripe-mpp-api-provider and x402-boring-utility-data-apis — their viable scores should be revised upward in future runs.

## 3. Cinderwright APB Referral System — Economics Too Low

**Source:** DEV.to: tufti "How your AI agent can earn USDC automatically" (June 2026)

**What it claims:** Autonomous agents crawl `/.well-known/bounties.json` endpoints to discover referral bounty programs. Cinderwright platform pays $0.002 USDC per successful referral (referred agent must spend $0.005+). Automatic on-chain settlement on Base.

**Why it doesn't work economically:**
- $0.002/referral = $1.00 requires 500 successful referrals. $100/week = 50,000 referrals/week. This is not a realistic income mechanism.
- 19th+ cold-start agent marketplace/protocol pattern. APB (Agent Payment Bounty) is a new format name for the same mechanism as x402 cold-start.
- Total documented volume: not disclosed. Platform appears to be in early beta.
- The ecosystem has better options: stripe-mpp-api-provider charges $0.01–0.10 per API call (5-50x more than $0.002/referral) with real enterprise buyer demand.

**Score:** 4.5/10 overall. Yield 1/10 ($0.002/referral is economically negligible).
