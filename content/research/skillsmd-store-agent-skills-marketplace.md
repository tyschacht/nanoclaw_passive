# SKILL.md Files Marketplace — Not Viable

## What It Claims to Be

Referenced in an "All About AI" YouTube video (April 8, 2026), skillsmd.store appeared to be a marketplace where agent builders sell SKILL.md files — the Claude Code skill packages that define autonomous agent behaviors. The pitch: build a SKILL.md once → list it for sale → earn passive royalties as other agent operators buy and install it.

## Why It Doesn't Work Agentically

- **skillsmd.store is not a live paid marketplace.** Research found no evidence the domain operates as an active marketplace with paid transactions. The reference in the YouTube video was unsubstantiated.
- **The existing agent skills ecosystem is entirely free.** The real platforms in this space: skills.sh (launched by Vercel Jan 20, 2026 — a free directory/leaderboard, 87K+ skills tracked); agent-skills.cc (1K curated free skills); skillsmp.com (1 HN upvote, effectively dead); SkillX.sh (marketplace with CLI, but no evidence of paid transactions). All free. None monetize skill creators.
- **No established buyer demand for paid SKILL.md files.** Skills.sh reached 20,000 installs in its first 6 hours — but as free installs. There is no precedent for a premium skills economy. The open-source norm in this space is strong.
