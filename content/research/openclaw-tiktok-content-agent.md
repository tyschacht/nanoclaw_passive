# OpenClaw TikTok Content Agent for App MRR — Not Viable

## What It Claims to Be

Developer Oliver Henry built an OpenClaw AI agent called "Larry" that drove 500,000+ TikTok views and nearly $1,000 MRR for his app "Snugly" (a room design visualization tool). The agent generates carousel image posts with AI visuals, writes captions, selects hashtags, and schedules content to TikTok via Postiz/API. Widely circulated on Wealthy Tent and marketing blogs in April 2026.

## Why It Doesn't Work Agentically

- *Human-in-the-loop for every post.* Oliver explicitly states the workflow requires him to "open TikTok, pick a trending audio track, attach it to the post Larry had already drafted, paste the pre-written caption, and hit publish — all in approximately sixty seconds." That 60-second manual intervention per post is irreducibly human. TikTok's API does not allow fully automated audio selection and publishing for promotional content.
- *Revenue is from an existing SaaS, not from the agent.* Larry doesn't earn money — it drives traffic to Snugly. The agent is a marketing tool for a separately built and monetized app. Without the existing SaaS, the agent generates nothing. Building the SaaS itself requires human effort.
- *TikTok content automation ToS risk.* TikTok has progressively restricted API-based automated posting for non-registered marketing partners. The Postiz integration operates in a gray zone that could be suspended.
