# Wave 15 Bundle — Not Viable

Three items evaluated and eliminated this run. All fail the agentic passive income test for distinct reasons.

---

## 1. MuleRun Creator Studio — Dual-Credit Economy

### What It Claims to Be

MuleRun (mulerun.com) launched "Creator Studio" in December 2025, positioning itself as "the world's first platform built for AI agent monetization." Creators build agents (or use the upcoming no-code Mule Agent Builder), publish to the MuleRun marketplace, set their own pricing (per-call, per-minute, etc.), and earn "nearly 100%" of revenue. The platform claims "millions of agent calls" and offers cash bonuses of $100-$10K based on adoption.

### Why It Doesn't Work Agentically

- *Dual-currency trap*: MuleRun pays out in two types of "Earned" value — "Earned Credits" (from consumers who used trial/free credits to pay) and "Earned Cash" (from consumers who paid with purchased/subscription credits). Only Earned Cash can be withdrawn to a bank account. Earned Credits expire within 2 years and cannot be converted. Since trial users likely represent a large share of usage, effective withdrawal rate is unknown and potentially low — similar to the BotCoin/virtual currency red herring pattern.
- *Semi-manual listing*: The Creator Studio submission process requires "collaboration with MuleRun" for commercialization — not self-service. The listing is not fully autonomous.
- *No-code builder not live*: The "Mule Agent Builder" (one-click no-code agent creation) was listed as "scheduled for release in early 2026" as of December 2025 — it may not yet be available.
- *Discovery opaque*: No documented buyer base statistics. "Millions of agent calls" on the platform total does not translate to marketplace buyer demand for new listings.

### Scores

| Criterion | Score (1-10) | Notes |
|---|---|---|
| Agentic viability | 5 | Building agent is agentic; listing requires collaboration; payout depends on paid-credit user % (unknown) |
| Setup effort | 4 | Must build working agent + apply as creator + collaborate with team for listing |
| Yield potential | 4 | Dual-credit system means effective cash earnings are a fraction of total earnings; unknown ratio |
| Risk | 8 | Low legal risk; ToS appears reasonable |
| **Overall** | **5.25** | Below VIABLE threshold; dual-credit economy disqualifies |

## 2. Circle Agent Marketplace — Curated Directory, Not Self-Service

### What It Claims to Be

Circle Internet Group (USDC issuer, NYSE: CRCL) launched "Circle Agent Stack" on May 11, 2026, including an "Agent Marketplace" at agents.circle.com. The press release describes it as "a curated directory of agentic services that both humans and AI agents can browse, evaluate and integrate with, enabling agents to discover and pay for services programmatically." Sellers have dashboards with earnings and cross-chain USDC withdrawals.

### Why It Doesn't Work Agentically

- *Curated = gated*: "Curated directory" explicitly means Circle selects which providers are listed — not a self-service developer marketplace. No self-service provider registration page found in launch materials or agents.circle.com documentation.
- *Same pattern as prior corporate marketplaces*: Anthropic Claude Marketplace (enterprise partnerships only), Humain One (Saudi PIF + Turing, partnership agreements required), Google Cloud Marketplace (Partner Advantage required) — all follow the same gate-first pattern. Circle Agent Marketplace appears to follow this model.
- *No individual developer onboarding confirmed*: Launch announcement describes marketplace from a buyer/consumer perspective only; no documentation of how solo developers or individual agents enroll as service providers.
- *Infrastructure focus*: The valuable Circle Agent Stack tools (Agent Wallets, Nanopayments at $0.000001) are spend-side infrastructure for agent builders — not earn-side income mechanisms for solo operators.

### Scores

| Criterion | Score (1-10) | Notes |
|---|---|---|
| Agentic viability | 3 | No confirmed self-service provider enrollment; cannot autonomously list services |
| Setup effort | 3 | May require partnership agreements, vetting, enterprise relationship |
| Yield potential | 5 | USDC payments, cross-chain withdrawals are good infrastructure — but unknown if accessible |
| Risk | 8 | Circle is a regulated, reputable company |
| **Overall** | **4.75** | Below threshold; re-evaluate if agents.circle.com adds self-service provider registration |

## 3. PutHouse.com AI Options Selling — Capital-Dependent Trading

### What It Claims to Be

PutHouse.com appeared in a Reddit post (r/passive_income or r/AIIncomeLab) claiming an AI system autonomously sells covered calls and cash-secured puts on stocks via broker APIs (Interactive Brokers or Alpaca), earning $6K in options premiums over a period when underlying stocks gained $42K. Framed as "autonomous passive income" via AI.

### Why It Doesn't Work Agentically

- *Capital-dependent income*: Options premium income scales with position size, not agent labor. To earn $6K/month in covered call premiums, you need roughly $200K-$400K in underlying stock positions. This is asset management, not labor-based income — same "DeFi yield optimization" red herring in a different wrapper.
- *Market risk*: Covered calls cap upside; cash-secured puts expose capital to stock declines. During a downturn, premium income is far exceeded by position losses. The $42K stock gain alongside $6K premium is cherry-picked from a bull period.
- *Same pattern documented*: Already covered under "DeFi yield optimization as agentic income" red herring (Coinbase CDP Yield Seeker pattern) and Broker-CLI (north-brook/broker-cli) evaluation (Run 10). "Autonomous trading via agent" = capital-dependent regardless of the asset class.
- *Broker API friction*: Interactive Brokers and Alpaca have different options API surfaces; Alpaca doesn't offer true options trading in all markets; IBKR requires real portfolio margin setup. Not trivial to set up autonomously end-to-end.

### Scores

| Criterion | Score (1-10) | Notes |
|---|---|---|
| Agentic viability | 7 | Agent CAN execute the options strategy autonomously — but income scales with capital, not work |
| Setup effort | 5 | IBKR/Alpaca API setup is non-trivial; options-enabled accounts require manual approval |
| Yield potential | 3 | $6K/mo requires $200K+ capital deployed; not viable without substantial starting capital |
| Risk | 3 | Capital-at-risk; market downturns can wipe premium gains; assignment risk |
| **Overall** | **4.5** | Below threshold; capital-dependent pattern disqualifies regardless of agent capability |
