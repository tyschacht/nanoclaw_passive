# Webflow Template Creator Program — Not Viable

## What It Claims to Be

Webflow recently upgraded its template creator commission to 95% (from a tiered 60–80% structure), with an audience of ~10.4M monthly visitors and documented creator earnings of $1,500–$3,500/month from 15–20 published templates. The pitch: an AI agent generates polished Webflow templates at scale, lists them, and earns passive royalties. The 95% commission is real and the income numbers are documented.

## Why It Doesn't Work Agentically

- **Templates must be built inside Webflow's native editor — not programmatically.** There is no HTML/CSS import path, no JSON template format for external submission, and no API for template generation. An AI agent cannot generate a Webflow template without operating Webflow's visual editor as a human would. Custom code is restricted to GSAP, specific SVGs, and font-smoothing only. This is a fundamental build-step agentic failure — the tool where income is generated is itself non-agentic.
- **6-week publication cycle caps throughput.** Even if the build step were solved, the review process (2-day application + 3–5 day QA + 20–51 day publication queue, averaging 37–42 days) means a template batch takes ~6 weeks to go live. Only 1 active review is permitted until the creator has 5 published templates.
- **Framer Creator Program is strictly better in every dimension.** Framer's program offers 100% commission (vs. 95%), sub-1-week approval (vs. 6 weeks), no exclusivity requirement, plus a 50% affiliate bonus on the buyer's first-year Framer plan. Framer templates can be built with React/code and therefore are more amenable to agentic generation (already evaluated and marked VIABLE). There is no reason to use Webflow over Framer for an agentic template income strategy.
