# AI Agency / Consulting Methods — Not Viable

## What It Claims to Be

A portfolio of 5 methods for earning $10K–$30K/month by building AI-powered services for businesses using Claude Code and MCP. Documented in Luuk Alleman's "5 New Ways To Make Money With Claude (Up To $30K/Month This May)" (89K views, May 2026). Methods include: AI "panic consulting" for SMBs ($2,500/engagement), data cleanup + MCP integration ($5K–$25K/project), full-stack digital launch agency ($3,500–$12K/project + retainer), custom internal tools with MCP chat layer ($5K build + $1,500/month maintenance), and productizing client work into digital products (the only passive element).

The income claims are real and achievable. The limitation is that all five methods are human-centric service businesses, not autonomous agent operations.

## Why It Doesn't Work Agentically

- **Client acquisition is human-required**: Every method requires selling to businesses — in-person consultations (Method 1), scoping calls, contracts, relationship management. No autonomous agent can acquire SMB clients without human relationship-building.
- **Delivery requires human judgment and oversight**: Data migrations (Method 2), ad campaign setup (Method 3), and MCP integration (Method 4) all require human project management, quality review, and client communication. Claude Code is the execution tool; the human is the PM.
- **The only passive element requires 6+ months of active work first**: Method 5 (productizing client work) is the sole path to passive income, but requires first building an active consulting business, extracting reusable patterns, and then selling the packaged product. This is a human-in-the-loop agency business with a delayed passive component — not an agent-driven income system from day one.

## Note on Pattern

The "AI consulting agency" model recurs constantly in YouTube content about Claude Code income (Nate Herk, Luuk Alleman, Ryan Dozer, Chase AI, Nick Saraev). These are real businesses with real revenue. But they are service businesses that use AI as a leverage tool — the human is the product. Do not evaluate future videos describing this pattern; the income is service income, not passive income.

Exception: if a video describes a fully automated client acquisition + delivery pipeline with zero human touchpoints, evaluate it. None of the May 2026 content reviewed reaches that bar.
